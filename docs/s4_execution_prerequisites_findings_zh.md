股票退出原队列、停止上市或代码变更的缺失，必须保留原因，不能随意删掉原持仓。

旧回测器已能冻结缺价和生命周期阻断持仓，不能说完全没有冻结逻辑。它的持仓是连续
金额，以复权价格标记，费用是成交金额的统一比例；仍缺针对历史日线的整数股数、
涨跌停方向、最低佣金、参与率和公司行为现金账本。执行侧日线并不构成成交证据，
这个限制也不能因接入研究回放而消失。

下一项先做一个**独立的假设成交数量/现金核心**，只跑人工构造的会计案例：卖不出去
就保留股数，只有已模拟完成的卖出才增加可用现金；当日买入不能当日卖出；容量不足
只能部分成交；买入必须连手续费一起负担；证据未知不强行通过。随后再用有界任务
处理31只分红原始响应、2020—2022规则范围和逐股历史资料。现在不需要把所有实盘
账户、券商接入或公告文本模块做完才开始这项工作。

未来回放必须分开复权选股价格与未复权成交价格，分红应收和实际可用现金分开；未付款
不能提前拿来买股。分红与复权收益不能重复入账。个人股息税需要取得日期和持有批次，
不能因为常见调仓周期较短就删除这项成本。成交额上限应使用决策时已知的前20日资料，
同时实际日容量只能作为成交阶段的约束；二者都不是观察到的收盘竞价可成交数量。
滑点只可写成预注册情景，现金收益继续不添加。
