# S5-B 单次诊断结果封印

`S5BaseDiagnosticRunSeal` 位于纯指标计算和以后本地持久化 runner 之间。它不会
保存行情或统计明细，只绑定以下证据：

- 冻结协议 fingerprint；
- readiness fingerprint；
- 已验入 outcome 输入包 fingerprint；
- 由输入包独立重算得到的指标 fingerprint；
- 唯一运行序号、运行预算和 UTC 记录时间。

## 单次预算

冻结协议的 `run_budget=1`。第一次合法结果产生 ordinal 1。后续如果协议、
readiness、输入和指标完全相同，则视为基础设施重试，直接返回原 seal，并保留原始
记录时间；这不会形成第二次研究观察。

同一协议下只要 readiness、输入或指标发生变化，就属于另一份证据，seal 会拒绝。
ledger 中已有重复 run id，或同一协议已有多条记录时也会失败，不能挑一个看起来
更好的结果继续。

## 防止伪造结果

调用方传入的指标不会被直接相信。seal 会再次从已验入输入包运行纯指标内核，并要求
完整 dataclass 与 fingerprint 都一致。调用方时间必须带时区，进入 seal 前统一转换
为 UTC，避免同一时刻因时区表示不同产生不同证据。

该封印只表示“单次历史诊断结果已完整形成，等待用户明确审阅”。它不判断策略优劣，
不冻结持仓期，不允许参数重扫，不授予绩效声明、策略晋级、账户变更或券商下单权限。
持久化与原子写入属于后续本地 runner 的职责。
