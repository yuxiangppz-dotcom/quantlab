# F7融资余额资料：新增资金流研究路线

这条路线检验融资余额变化是否包含超出既有反转信息的排序线索。融资余额是
尚未偿还的融资金额，不是已经识别的“主力净流入”；退出融资标的名单后仍
可能有未偿还余额，不能由数值存在推定股票可融资或可买入。

在读取新数值前，已经固定后续公式：用此前一个共同交易日的融资余额与其
五个交易日前的差，除以这五日成交额。六个连续融资观察和五个有效成交额
缺一不可；缺行、非融资证券与负数都不能补成零。方向、窗口和原256股范围
固定。后续只做与相同样本20日反转的排序比较，不直接推导收益。

[官方接口文档](https://tushare.pro/document/2?doc_id=59)提供单证券起止日期、
6000行上限和元单位；说明前日资料通常次晨更新，深交所周五资料在周一上午
更新。滞后一个共同交易日只是探索性对齐，不能替代真实历史发布时间与修订
记录。因此即使下载成功，也不自动通过历史PIT或收益验证。

采集只用原2019固定256股，每只一次2019-12-24至2024-12-30区间请求，保存
原始响应及观测时刻；不调用独立付费权限，不改正式数据目录，不读取标签，
不训练模型或启动经济路径。后续诊断需要单独的有界任务卡。
