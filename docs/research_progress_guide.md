# 查看策略研究进度

打开本地 QuantLab：<http://127.0.0.1:8501/>，在左侧选择 **策略研究进度**。

本页用于了解研究做了什么、发现了什么，以及哪些结论还不能用于交易。

1. 看上方用量：资金流指标、组合回测路径、模型拟合是不同工作，不能互相替代。当前页面标明首批记录范围，不是无限实验计数器。
2. 看五类策略的进度：取得数据清单、完成因子诊断、通过收益检验是三个不同阶段。
3. 看逐年关联表：正的数值只表示排序方向有一定关系，不是百分比收益，更不能直接理解成年化收益。
4. 在“成分对照区间”中切换全段、前段和后段。它检查新增资金流是否比原有价格信息多提供了帮助，所有区间均是已经观察过的历史。
5. 需要复核时下载诊断报告、成分对照报告或逐年表。完整精度保留在下载文件中；页面保留四位小数方便阅读。

“分块重采样95%区间”表示这一关联估计在重复抽样下的波动范围。区间跨过0，说明当前证据仍难以区分稳定的正向或负向关系；即使不跨0，也不能据此认定策略将来能盈利。交易成本、无法成交、历史信息是否真的当时可得，都要另行通过检查。

未完成独立复核时，相应结果不会展示。记录校验失败时页面会显示错误，请保留文件，不删除记录或重新运行以覆盖失败。此页面没有下单和数据采集按钮。

研究会按已批准的每2小时安排继续，每轮约90分钟有效工作并预留收尾空间；只有重要发现、失败或需要你处理的事项才通知。电脑需要保持开机且相关运行环境可用。当前还没有策略通过你的最终晋升确认，旧的股票排名和演示组合不能当成这轮研究推荐。
