# 第二轮研究结果怎么用

双击桌面的 QuantLab，进入“回测与基准”。页面依次显示费用试算、第二轮因子与模型研究、
已有历史回测。佣金暂按万分之 0.86，股票最低 5 元、ETF 最低 0.1 元，股票卖出另计印花税；
研究相关性表没有扣费，也不是可成交净收益表。

1. 在“第二轮”选择 5、10 或 20 个交易日预测区间，查看同一批有效样本中的七组信号。
2. 先看验证期平均 IC，再选择候选查看年度稳定性。IC 是排序相关性，不是收益率。
   训练期参与了模型拟合；2025 年以后的回顾期此前已观察过，不是全新的样本外检验。
3. 展开“样本覆盖与研究限制”，检查缺失特征、标签跨期和标签缺失排除了多少样本。
   标签缺失可能与停牌、代码切换、上市退市有关，不能忽略这些覆盖限制。
4. 下载完整诊断报告，保留全部 21 项比较和模型失败记录。没有结果时页面会明确提示。

这一步用于判断哪些信号值得继续研究。它尚未验证扣除完整成本后的收益、实际持有规则或
最大回撤不超过 20% 的目标，不会把研究模型自动用于日报、参考计划或券商账户。
真正前瞻仍按当日截止时间登记，不能把今天训练的模型回填成过去的预测。

日常操作继续使用 [快速入门](quickstart_zh.md)：更新数据 → 生成日报 → 登记前瞻 →
导入自己的账户记录并检查参考计划。模拟账户仅供熟悉流程，不代表实际成交或盈利。

## 维护与复核

本轮固定配置在 `config/research_round2_v1.json`，数据、模型、日志全部位于 WSL 项目的
`data/products/research_round2/research_round2_20260911`，实际使用 D 盘空间，不进入 Git。

维护者在项目目录依次使用 `uv run --extra research python -m
quantlab.research.round2_diagnostics prepare` 和同模块的 `run` 操作。
准备数据要求干净、已提交的代码；运行前后核对来源。每轮结果目录只能创建一次，每个模型
训练意图先落盘，失败不会自动重训；已有目录将拒绝重复运行，以免无意增加候选次数。
这两项维护操作并非日常更新按钮，也不应为寻找更好成绩而反复执行。

`uv run --extra research python -m quantlab.research.round2_diagnostics verify`
会重新校验所有阶段和模型文件。页面只读取已经封存的报告，校验其指纹和阶段身份；
历史报告描述的是当时绑定的数据版本，不声称当前正式数据目录从未变化。
