# S5-B 首次诊断准备度门禁

本门禁位于冻结协议和首次历史结果之间。它只回答一个问题：当前完整、事前声明的
股票/日期人口，是否已经具备加载未来 1/5/10/20 日结果的资格。

## 全量阻塞原则

门禁不会为了通过而删除股票、日期或较长观察窗口。以下任一条件失败，结论统一为
`blocked_before_outcomes`，可运行起止日期保持为空：

- 行业成员审计人口与预声明人口不完全相同，或任一成员不是
  `covered_verified`；
- 研究资格证据缺失、额外出现或不为正；
- 信号日前不足含当日 120 个有序市场 session；
- 1/5/10/20 日任一终点越过冻结期末；
- 中证全指基准缺少信号日或任一期内终点。

全部通过时才返回 `ready_for_single_frozen_run`，并且允许的起止日期必须与
原始意图完全相同。

## 防未来数据

市场 session 和基准覆盖只消费冻结期末及之前的日期。调用方即使传入冻结期后的
额外日期，也不能改变门禁结论或证据指纹。收益、NAV、成交、订单和账户数据根本
不在函数输入中。

输出绑定冻结协议、行业成员审计、研究资格、基准日期和市场 session 的内容指纹。
它不是回测结果，不消耗唯一一次诊断预算，不证明收益，也没有下单权限。
