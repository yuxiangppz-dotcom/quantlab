# S6 市场输入语义准入契约

状态：provider-neutral、无数值的冻结边界（v1）

## 为什么需要单独契约

仓库当前同时存在原始收盘价、用于收益序列的累计因子调整价，以及总市值、流通市值等字段。它们都有合理用途，但不能因为名称相似就互换进入 EP、BM 等估值公式。

本契约只回答“一个市场字段的语义是否足够完整，可供日频 PIT 估值公式后续绑定”。它不读取行情，不执行公式。

## 每条定义必须说明

每条定义由 `provider_id + source_id + raw_field_id` 唯一识别，并记录：

- 稳定的语义字段 ID；
- 收盘价、股本数量或市值；
- 原始未复权价、累计调整价、not applicable 或 unknown；
- 总股本、流通股本、自由流通股本、not applicable 或 unknown；
- 价格/市值的币种；
- 交易所收盘、盘中快照或 unknown 观察时点；
- 按交易日当时状态、事后回填重述或 unknown 公司行动口径；
- 证据状态和文档内容指纹。

类型内部必须一致：收盘价不能声明股本范围；股本数量不能声明价格基准或币种；价格和市值必须有三位大写币种；市值必须同时声明价格基准和股本范围。

## 日频 PIT 估值准入

`semantically_admissible` 只在以下条件全部满足时为真：

1. 定义及文档证据已核验；
2. 观察时点是交易所当日收盘；
3. 公司行动口径是交易日当时可观察状态，而非事后回填重述；
4. 收盘价和市值采用原始未复权价格基准；
5. 股本数量和市值明确总股本、流通股本或自由流通股本范围。

因此，`ResearchDailyPrice.adj_close` 仍可用于收益序列，但不会因为它是一个“价格”就自动取得估值输入资格。盘中快照也不混入当前日频收盘契约。

## 证据与目录

目录确定性排序并保留 `verified`、`provider_documented_unverified` 和 `unknown` 三类定义及计数。verified 只表示证据等级；如果价格基准、股本范围、时点或公司行动口径不符合日频 PIT 估值约束，定义仍然不准入。

## 明确不授权

本契约不包含任何数值，不调用供应商，不写 Canonical，不计算市值或因子，不产生排序、回测、绩效、仓位、风控、账户或订单权限。公式绑定审计现在可以显式接收本目录，但该绑定仍然只处理元数据和指纹。
