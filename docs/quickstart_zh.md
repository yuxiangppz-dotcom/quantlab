# QuantLab 中文快速上手

QuantLab 是你本机上的 A 股研究、组合参考和手工账户记录工具。
先用演示账户熟悉流程，再录入自己的真实账户。

## 打开与关闭

- 双击桌面的 **QuantLab**，浏览器会打开 `http://127.0.0.1:8501`。
- 重复双击会复用已有服务。页面只在本机开放。
- 关闭浏览器后服务仍在运行；双击 **Stop QuantLab** 可以停止服务。
- 工具没有设置开机启动。重启电脑后，再双击 QuantLab 即可。

## 每天收盘后这样使用

1. **开始使用**：确认“行情截止”和“日报日期”，不要把旧日报当成今天。
2. **数据状态与日报**：展开“更新本地市场数据”，确认范围并开始更新。
   成功后点击“生成/刷新日频报告”。正常更新只补最近最多 5 个交易日，已有行情保留。
3. **股票排名与因子**：查看目标组合、评分、风险提示，需要时下载排名和日报。
   目标持仓是研究输出；实际数量、价格和可交易性仍需复核。
4. **前瞻观察**：在信号当天北京时间 **16:00 至午夜前**登记，日报也必须在此期间生成。
   次日补记不算有效前瞻。之后可检查成熟标签，20 个交易日标签成熟前不作收益结论。
5. **账户与参考计划**：选择演示账户，点击“生成下一交易日参考计划”体验。
   BUY / SELL / HOLD / NO_TRADE 分别表示参考买入、参考卖出、持有、不交易。
6. **资金流水与估值**：自己的账户可导入真实出入金，保存原始收盘价估值，并与券商核对。

## 录入自己的账户

在“账户与参考计划”下载空白账户模板，保留全部表头。

- `account_id`：你自定的唯一账户名，如 `my_account`。
- `account_mode`：真实手工记账填 `manual_tracking`；演示填 `demo_simulation`。
- `as_of`：完整快照的时间，必须带时区，如 `2026-09-10T15:30:00+08:00`。
- `cash_cny`：这一时刻的真实现金，各行重复同一数值。
- 每只持仓一行，填证券代码、总股数、可卖股数。仅现金账户的股数都填 `0`，证券代码留空。
- `open_orders_declaration`：只有确认无未完成委托时才填 `none_declared`；未知应如实写 `unknown`。

导入的是完整账本起点。此后仅录入起点之后发生、且未包含在快照中的成交和出入金。
同名账户的新快照会切换起点，旧快照和旧账本保留并分别绑定；不要重复计入旧成交。

实际成交与出入金均先“预览并校验”，核对后再“确认导入”。成交时间、入账时间和实际费用
应来自真实记录；不知道就先补齐证据，不填猜测值。上传文件或账户状态改变后需要重新预览。

## 常见情况

| 页面提示 | 处理方法 |
|---|---|
| 数据落后、日历未知 | 更新数据后再生成日报；源数据尚未完整时稍后重试 |
| 前瞻不能登记 | 检查信号日期和生成时间；超时就等下个交易日，不能补造历史前瞻 |
| 参考计划被阻止 | 按提示核对账户时间、未完成委托、可卖数量及规则；保留未知状态 |
| CSV 导入失败 | 使用原模板，检查时间含时区、金额至多两位小数、证券与股数正确 |
| 估值与账户不一致 | 先核对成交、出入金和分红送转，再保存新的估值 |
| 页面打不开 | 重新双击 QuantLab；仍失败可将错误文字交给开发任务排查，不发送 Token |

## 当前能力边界

可做：本地行情更新、研究日报、前瞻登记、手工成交与出入金记账、参考计划和估值留档。
尚未完成：完整公司行动入账、历史任意时点账户回放、可靠的账户收益归因及正式券商接入。
没有策略因本次交付自动晋级，历史回测和演示账户不能证明未来盈利。
