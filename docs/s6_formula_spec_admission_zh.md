# S6 财务指标公式规范准入

状态：仅元数据的 provider-neutral 契约（v1）

## 目的

S6 后续会讨论 EP、BM、现金流收益率、ROE、ROA、毛利质量、杠杆和应计质量等候选指标。不同定义可能使用不同输入、期间、方向和异常值规则。若先看历史收益再补公式，很容易产生数据挖掘和不可复现结果。

本契约要求公式在读取结果之前把重要选择写清楚，但当前版本不替研究者选择任何具体候选公式，也不执行计算。

## 公式规范必须声明

- 稳定的指标 ID 和 value、profitability、quality、leverage 家族；
- 有固定顺序的输入引用，来源可为财务字段、市场字段或另一派生指标；
- identity、ratio、difference 或 sum 运算结构；
- 指标方向：越高越好、越低越好或 unknown；
- 财务期间对齐：相同财务期或最新 PIT 兼容；
- 输入缺失时排除观察或终止运行；
- 比率分母为零、为负时的独立政策；
- 公式文档与经济动机的内容指纹；
- verified、draft unverified 或 unknown 证据状态。

输入位置必须从零连续，输入身份和语义引用必须唯一。identity 必须有一个输入，ratio/difference 必须有两个输入，sum 至少两个输入。派生指标不得引用自身，目录也拒绝跨指标循环依赖。

## 准入与保留

草稿和 unknown 公式可以进入目录，方便保留未完成和负面证据，但不能被标记为 admitted。以下任一项都会形成显式阻断原因：

- 公式证据未验证；
- 文档或经济动机证据缺失；
- 指标方向、期间对齐或缺失值政策未知；
- ratio 的零分母或负分母政策未知。

非 ratio 公式必须把分母政策标记为 not applicable。ratio 不能这样标记；零分母也不能使用 allow signed，因为零不存在可保留的符号除法结果。

## 当前边界

“规范 admitted”只表示元数据决策完整，不表示该公式已被选为 S6 候选，更不表示供应商字段已映射、数据可用或计算结果有效。目录固定声明：

- 不冻结具体候选公式；
- 不包含财务或市场数值；
- 不授予指标计算权限；
- 不产生绩效、晋级、账户或订单权限。

具体 EP、BM、ROE 等定义必须在后续独立任务中逐项预声明，并在获得字段与版本证据后才能进入合成计算内核。
