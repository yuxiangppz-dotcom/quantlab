# S5-B 首次历史诊断协议说明

首次诊断观察信号日收盘之后 1、5、10、20 个交易日的变化。加入 1 日是为了判断
“准备拉升”是否会迅速兑现；保留更长窗口，是为了区分短促反弹与持续走势。

这些窗口不是持仓限制。协议明确把它们定义为信号日收盘到未来收盘的研究标签，
并将 `holding_policy_frozen` 固定为假。未来若研究一日持仓，需要单独定义信号何时
可知、下一交易日如何成交、何时最早可以卖出，以及停牌、涨跌停和交易成本。

诊断只能使用行业归属 100% 通过 PIT 审计、研究资格完整、基准证据可用且未来窗口
不越过冻结期末的样本。任何条件不满足都必须停止，不能缩小分母挑选可用日期。

协议只允许一次冻结运行，不允许看到结果后重扫阈值或重选时期；负月份、现金日期、
失败状态和缺失对照都必须保留。它不包含任何收益结果，也没有下单权限。
