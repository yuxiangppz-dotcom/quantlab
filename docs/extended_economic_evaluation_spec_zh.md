# 扩展频率对照的最小组合与成本评价规格

本文件固定后续评价口径；当前规划没有计算收益、创建订单或增加拟合。
读取现有 `portfolio/constructor.py`、`backtest/engine.py`、`portfolio/control.py`、
`research/portfolio_validation.py`、`research/costs.py` 和日期化规则证据后，
确定先连接已保存分数与可复核的组合意向，再实现独立版本的成本情景适配。

## 比较对象和资金路径

对2025-09-01至2026-08-31的固定全部信号交易日，保留岭回归与LightGBM、
每周更新与每月首次周更更新这四种模型/频率组合。只按当日分数降序、股票标识升序
打破并列，最多20只，目标总仓位80%、单只最多4%；不足名额不补未来赢家，剩余留现金。
预测成员由固定生命周期与特征条件决定，不能用之后的收益、公司行为或成交资料筛成员。

分别建立持有5/10/20个交易日和假设资金5万/20万/100万元的独立资金路径。
每条路径从第一个信号日开始，之后每H个信号交易日才形成下一次调仓意向。
只采用这个事前固定的初始相位，不搜索有利调仓日。它们是不同情景，不能相加成用户账户。
不把过去每日生成的重叠持有窗口累加为组合收益；同一路径始终只有一个持仓、现金与费用账本。
持有期限是计划调仓间隔；停牌或不可卖时实际持有可能更长，不能虚构按时退出。

信号在收盘后形成，意向最早下一市场交易日生效。保留信号、目标、待执行、受限、
情景成交与真实回报的状态区别；当前没有真实成交信息。尾部不足H天不强制制造平仓，
标明未结束持仓及观察截止；缺价格不以零值退出。无合格目标时现金与空仓规则需显式区分
“明确清仓目标”与“缺少信号”的不操作语义。

## 先保留现有引擎的事实边界

现有研究引擎按持仓价值、冻结生命周期、正数执行延迟及线性成本率求解自融资路径。
它的现有净值不是已核验的券商整股、逐单最低收费、股息税全成本账户。
不能只把万分之0.86传成线性费率，就声称包含5元最低佣金；也不能在净值生成后简单减费，
忽略费用对买入数量和可用现金的反馈。原有正式回测及其冻结语义继续保留。

最小下一实施步骤：生成固定目标序列和同源等权对照，验证信号/执行延迟、现金守恒、
停牌持有冻结、新目标无价留现金、退市/结算和策略-基准对称性；在明确的旧引擎情景口径下
报告结果与限制。整股与逐单费用另加有版本的情景适配器，旧引擎接口/正式结果不被覆盖。
新适配器只有通过下述现金、费用、约束和公司行为测试后才能产生更完整的成本情景；
两条实现的差异必须归因，不能混用成交与净值口径。

## 成交意向、费用与未知证据

整股适配读取有日期和板块来源的订单数量、最小单位、涨跌停与T+1规则，不把所有股票
统一假设为100股或把所有报价视作可成交。账户可卖量、停牌、限价、交易能力与规则证据
不足时维持未知状态；受限持股留在账上，无法买入的资金留现金。情景成交必须清楚标记
采用的报价时点、价差、成交能力假设与缺口，不能写入真实订单/成交回报目录。

同日同股票同方向的计划量先净额化为情景订单，再按订单金额计费，最低佣金不能按
独立研究窗口重复收取或随意拆单降低。先卖后买及费用预留必须进入自融资求解，禁止
负现金或靠未来卖出款提前支付。买入按已知规则向下取可负担数量，零股/余额卖出按对应
日期规则处理；规则未知不自动取整。每笔量、价、金额、费用与剩余现金可逐项勾稽。

沿用已保存用户费用情景：佣金万分之0.86、股票最低5元、ETF最低0.1元，印花税不包含
在佣金中。本研究对象仍是A股股票，ETF设置保留而不扩展品种。逐单佣金和日期化股票卖方
印花税复用 `research/costs.py` 的已核对分项与按分舍入；该报价不是历史券商收费凭证。
其他收费是否已包含、实际冲击和股息税未证实，完整费用保持未知。
每边0/5/10/20基点只作为预先固定的额外滑点敏感性分项，0只是试验基准，不能声称实际无滑点。
不以某个敏感性档位表现最好反过来选费用假设。

分红输入使用最新原始观察和事件桥接，并保留版本、冲突及实际观察时间。
不能把预案相加、复权因子变化直接当现金、当下下载的历史记录倒填为历史信号。
权益须匹配实际或明确情景持股批次、股权登记/除权/支付/股份上市时间；税款期限不能用
交易日代替自然月/年。缺批次、金额、日期或税负依据时，相关权益保持未知。
仅可展示已知费用分项、明确排除权益的价格情景与未知缺口，不能将其命名为完整净收益。

## 验收与输出

预测比较按完整周次、月份及整个固定区间，保留所有结果、缺失及共享模型周次；
共享周不计更新频率优势。因标签重叠、历史反复被观察，不作独立样本显著性或新前瞻声明。
经济路径需验证现金守恒、单侧最低佣金、舍入、资金不足、同日净额化、T+1限制、持仓冻结、
无法平仓、未结束窗口和公司行为未知的传播。基准经过相同引擎、延迟、费用和生命周期规则。
同时输出覆盖率、未执行/受限数量、持仓/现金、费用分项、回撤和结果适用状态；缺关键证据
时收益与回撤须带相应情景标签，不能升级为完整净表现。

最大回撤20%仍是待验证目标。模型周更、规划完成或某个回测数值都不触发自动晋级、
真实订单或倒填前瞻。先评价预测与经济价值，复杂仓位覆盖和Alpha101/191另立固定任务。
