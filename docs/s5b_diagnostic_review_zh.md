# S5-B 冻结历史诊断审阅产物

`build_s5_base_diagnostic_review` 接收已经计算完成的 typed metrics 和单次 run
seal，输出带 fingerprint 的中文 Markdown。函数不读取本地行情、不访问数据商，也
不写文件；未来本地 runner 只需要负责把真实输入交给既有链路并原子保存产物。

审阅内容完整展示状态数量与比例、相邻已观测信号日迁移、每日研究目标与现金、
各状态 1/5/10/20 日标签分布、两个核心日期配对差值、五个冻结对照、月度分布和
同窗口宽基准环境分布。所有数字使用固定八位小数，空组显示为观测数 0 和 N/A，
不能被填成零或静默删除。

构建前会验证协议、输入、指标和 seal fingerprint 的绑定关系，并拒绝任何已经获得
持仓期、绩效、晋级、账户或下单权限的来源对象。Markdown 内容本身单独计算
content fingerprint，外层 artifact 再绑定全部证据身份。

该产物故意不生成“通过/失败”“建议买入/卖出”或最佳持有期。1、5、10、20 日只是
close-to-close 观察窗口，不会阻止以后单独定义持有 1 日。真实诊断完成后，是否继续
研究、冻结何种持仓规则或进入前瞻观察，仍需要用户明确审阅和新的任务授权。
