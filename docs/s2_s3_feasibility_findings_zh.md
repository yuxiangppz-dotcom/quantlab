# 估值、质量与行业策略：本次有界可行性检查

发现一个比历史版本更早的工程缺口：**当前采集器与正式DailyBasic结构没有保存
PE、PE_TTM、PB**。固定抽取的10个2019—2024分区也都只有代码、日期、换手率、
总市值和流通市值。这不是已计算估值策略但效果不佳，而是估值输入尚未接入。
已有量价/资金流研究未使用这些缺失估值字段，不能据此否定或重写原来的结果。

本次只检查12个数据文件和4个代码/限制说明文件，约2.50MiB；六次定向检索、五个
选定官方文档页面，228秒完成。没有调用数据接口、写正式数据、算因子/收益或训练。
10个分区的键无重复不代表全历史已经审计通过；不把抽样结论扩展为全库完整性证明。

| 策略路径 | 本次结论 | 接下来需要什么 |
| --- | --- | --- |
| S2-A估值 | 暂不进入历史收益排名 | 单独保留估值原始快照；核对财务分母与历史修订规则 |
| S2-B质量／盈利改善 | 历史质量阻塞；已有质量快照保留前瞻 | 核对结构化预告/快报的各次披露值，不能只有首次日期 |
| S2-C估值加资金流 | 基础估值尚未验入 | 不能绕过A换个名字开始回测 |
| S3-A行业趋势 | 缺历史行业成员输入 | 小批取得成员的纳入/剔除记录与分类版本，先核对覆盖 |
| S3-B、S3-C | 随基础行业路径阻塞 | 保留候选身份；不在不明行业归属上叠加质量或资金流 |

官方daily_basic文档确实提供估值字段，但PE/PB使用利润或净资产分母，不能从
trade_date字段就推出保存了当时财务版本。文档还说明日指标在交易日15—17点更新，
不能假设收盘瞬间已全部到齐。[每日指标文档](https://tushare.pro/document/2?doc_id=32)

本地质量快照有6078条记录，均属于2024年末报告期，首次本地观察为
**2026-09-10 09:38:22.182676（北京时间）**；均标记为首次观察后前瞻使用，来源ID无重复。
公告日期早于这个时刻也不能让这份后来取得的数据变成旧日已知信息。
available_from的日级日期还需与observed_at实际时分共同使用；不能推到当天零点。
官方财务指标的公告日和更新标识也不等于完整修订时间链。
[财务指标文档](https://tushare.pro/document/2?doc_id=79)

证券主表5900行，没有行业字段；正式数据目录中尚无历史行业成员、预告或快报数据集。
这仅指已检查的正式目录，不声称供应商没有数据。申万成员接口给出in_date/out_date，
但默认is_new=Y；只取默认结果会漏掉需要单独检查的旧成员。该接口文档要求2000积分，
在用户5000积分范围内，仍需实际响应检查与历史分类核对。
[申万成员文档](https://tushare.pro/document/2?doc_id=335)

forecast/express可以作为盈利改善来源候选，不等于现金流质量。forecast文档注明晚间
更新与首次公告日；express还含修正后的上年利润。新下载的历史行必须先核对对应
披露值和版本，不能挂到更早日期当作当时已知。
[预告文档](https://tushare.pro/document/2?doc_id=45)、[快报文档](https://tushare.pro/document/2?doc_id=46)
