# S6 公式财务输入 PIT 就绪门

- GitHub Issue：#182
- 父任务：#132（归属 #127）
- 起始 master：`5f255a4e6919b63d9cc96b35bef0915364fa1339`
- 分支：`chatgpt/s6-financial-readiness`

## 目标

将公式财务字段绑定、显式报告期、历史财务版本选择和字段语义准入合成一个直接财务输入就绪门。

## 包含

- 精确绑定审计、字段目录和完整版本库存指纹；
- provider/source、股票、报告期和 `as_of` 目标；
- 每个直接 `financial_field` 的绑定、版本选择和字段准入结果；
- 成功行固定定义、版本、字段审计三重指纹；
- 修订只在自身来源可用时间后替代原始版本；
- 缺失、未来、弱证据、跨来源替代和字段缺失均失败关闭；
- 确定性指纹和纯合成测试。

## 不包含

数值、供应商调用、Canonical 读写、跨期政策解析、市场门整合、派生指标展开、公式执行、排序、回测、绩效、组合、风控变更、晋级、账户或订单。

## 验收

至少存在一个直接财务输入且全部在指定 `as_of` 前选到同源已核验版本、包含精确原始字段并通过字段准入时，财务门才就绪；空输入不通过；完整 CI 通过。
