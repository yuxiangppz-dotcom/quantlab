# S5 v1：行业底部蓄势 / 反转策略任务卡

GitHub Issue：#128；上层多策略研究计划：#127。

本任务在读取任何 S5 历史收益结果之前冻结。它只实现一个纯研究内核，不取数、不回测、不训练模型、不登记前瞻、不改变 Strategy Registry、不生成订单，也不修改正在进行的 S4 PR #126。

## 研究假设

用户观察到一类市场结构：行业经历较长时间和较大幅度下跌后，在低位停止持续创新低，波动逐渐收缩；随后行业相对大盘开始转强，行业内部部分股票先于行业走强并出现更积极的量价结构。S5 尝试把这类结构变成可验证的规则。

“蓄势 / accumulation-like”只是价格、波动和成交结构的描述。系统没有投资者账户级数据，因此不得把它写成“已确认主力建仓”。

## v1 固定特征与阈值

行业必须同时满足：

- 距 120 日高点回撤不小于 25%：`drawdown_from_120d_high <= -0.25`；
- 最近 20 个交易日中刷新 60 日低点的比例不高于 10%；
- 当前 20 日实现波动率处于自身过去 252 日分布的 40% 分位或以下；
- 最近 20 日行业收益减基准收益严格大于 0；
- 上述窗口历史完整。

股票只有在所属行业通过后才继续检查，并且必须：

- 当日行业归属具有 PIT 证据；
- 当日研究股票池资格明确通过；
- 最近 20 日相对所属行业收益严格为正；
- 收盘价严格高于 MA20；
- MA20 相对 5 个交易日前的斜率严格为正；
- 最近 20 日上涨日平均成交量 / 下跌日平均成交量不低于 1。

缺失值保持 `unknown`。NaN、无穷、非法范围、日期错位和重复身份直接拒绝；它们不能被填成 0 或安全状态。

这些数字是首版研究假设，不是“优化后的最佳参数”。本任务禁止在看到历史表现后扫描 20%、25%、30% 等阈值来挑最好结果。

## 动态持仓数量

S5 不强制每天持有 20 只股票。

- 最大持股数：20；
- 每只目标权重：4%；
- 通过全部条件的股票按“相对行业强度 → 上涨/下跌量比 → 股票代码”确定性排序；
- 最多取前 20 只；
- 剩余全部为现金。

因此：

- 0 只通过 → 100% 现金；
- 5 只通过 → 20% 股票 / 80% 现金；
- 20 只及以上 → 80% 股票 / 20% 现金。

S5 自己不会为了凑满仓位而放大单只权重。后续已有 V/M/D 风险层只能在这个基础目标上继续缩仓，不能由 S5 重复实现市场风控。

## 分层边界

本模块输入的是已经计算好的 PIT 特征，而不是原始行情读取器。这是为了把两类问题拆开：

1. `S5 kernel`：给定合法的当日事实，规则是否确定、可复现、动态 N 是否正确；
2. `S5 input adapter`：行业指数、历史行业成员、基准、窗口价格和成交量是否真的在当时可得。

目前 QuantLab 的历史行业成员证据还不能被默认视为完整 PIT。因此本 PR 不进行历史 S5 收益回测。下一任务必须先审计并物化行业/成员输入，再单独冻结历史诊断窗口和评价指标。

## 成功标准

代码成功只表示：规则契约实现正确、未知状态不被伪造、输出 TargetPortfolio 守恒、排序和动态 N 可复现。

它不表示：

- S5 能赚钱；
- 用户举例的涨停股票证明了策略；
- 回撤一定低于 20%；
- 可以实盘；
- 可以自动晋级策略。

历史诊断和 Forward Shadow 都需要独立任务和证据。
