# S7 行业 ETF 趋势策略研究内核

- GitHub Issue：#186
- 父任务：#133（归属 #127）
- 起始 master：`37f0f827c2ac16f5c190c4395056dcd6fb784390`
- 分支：`chatgpt/s7-etf-trend-kernel`

## 目标

一次性实现 S7 的 provider-neutral 研究内核：固定候选池、PIT 资格、单一中期趋势规则、横截面相对强度、Dynamic N 和显式现金。

## 冻结规则

- 120 个交易日复权总收益严格大于零；
- 合格品种按该收益降序排列，代码稳定打破并列；
- Top 3，每个 30%，剩余现金；
- 每次决策独立重算，无持仓期锁定。

## 不包含

不把既有 ETF 接口探针当作策略池；不调用供应商、不读写 Canonical、不计算真实结果、不优化窗口、不晋级策略，也不产生账户或订单权限。

## 验收

候选池和决策均有确定性指纹；未来或未知证据失败关闭；正趋势排序、Dynamic N、现金和无持仓锁定规则由合成测试覆盖；完整 CI 通过。
