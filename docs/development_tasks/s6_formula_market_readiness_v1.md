# S6-A v8 公式市场输入 PIT 就绪审计

- GitHub Issue：#173
- 父任务：#132（归属 #127）
- 前置：#169/#170、#171/#172
- 起始 master：`7535d35823612ac2116f3143c6369e6912677b78`
- 分支：`chatgpt/s6-formula-market-readiness-v1`

## 目标

将公式市场字段绑定与历史市场观测选择合成一个直接市场输入就绪门，防止语义已绑定但记录尚未可用的字段进入后续计算。

## 包含

- 公式绑定审计、精确市场目录和观测目录指纹；
- 股票、交易日和 `as_of` 目标；
- 每个直接 `market_field` 的绑定与观测结果；
- 成功行绑定定义和观测记录双指纹；
- direct-market 全就绪与 market gate 两层汇总；
- 明确排除财务观测、派生展开和完整公式计算；
- 构造器不变量、确定性指纹和纯合成测试。

## 不包含

财务版本就绪、派生指标展开、任何数值、供应商调用、Canonical 写入、公式执行、排序、回测、绩效、组合、风控变更、晋级、账户或订单。

## 验收

绑定审计必须匹配市场目录精确指纹；至少存在一个直接市场输入且全部选到 `as_of` 前可用的已核验精确记录时，直接市场输入才全就绪；整份绑定未准入时 market gate 仍失败；`formula_computation_ready` 固定为 false；完整 CI 通过。
