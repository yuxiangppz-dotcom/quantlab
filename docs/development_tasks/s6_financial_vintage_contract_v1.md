# S6-A v1 财务版本库存契约

- GitHub Issue: #159
- 父任务：#132（归属 #127）
- 起始 master：`00a2068d62061ae27a7bb1df96256f2d38e4ee3f`
- 实现分支：`chatgpt/s6-financial-vintage-contract-v1`

## 目标

在不读取本地数据、不选择供应商、不定义财务因子的前提下，冻结 S6 价值+质量研究所需的财务报表版本、证据状态和源时间 PIT 选择边界。

## 范围

- 不可变财务版本元数据；
- 报告期种类与期末对齐；
- 带时区的公告、源可获得、本地取得时间；
- 四态版本证据；
- 原始字段 ID 与内容指纹；
- 确定性库存、状态计数、内容指纹；
- 最新可用已验证版本的 as-of 选择；
- 重复、冲突、倒序和未来不可见的失败关闭；
- 纯合成测试和中文契约说明。

## 不在范围

- provider 调用、凭证或许可判断；
- 本地 Canonical 读取或写入；
- 财务数值、字段映射、单位/币种转换、TTM；
- 价值/质量公式、权重、阈值或股票选择；
- 收益、组合、绩效、晋级、账户或订单。

## 验收

- 输入顺序不影响库存顺序和指纹；
- 弱证据与 unknown 被计数但不能被历史选择；
- 修订版本只在其 `available_at` 后替代原始版本；
- 后来 `retrieved_at` 不会被表述为历史本地已知；
- 所有冲突与缺失均显式失败关闭；
- 新增测试、Ruff、全量 pytest 和仓库 diff 检查通过。
