# S6-A v5 市场输入语义准入契约

- GitHub Issue：#167
- 父任务：#132（归属 #127）
- 前置：#159/#160、#161/#162、#163/#164、#165/#166
- 起始 master：`4560af3271402b70e782746021c6755cd5150861`
- 分支：`chatgpt/s6-market-input-admission-v1`

## 目标

冻结 provider-neutral 的日频 PIT 市场输入语义，阻止原始价、复权价、不同股本范围和事后回填字段在价值公式中被静默互换。

## 包含

- provider/source/raw field 唯一身份；
- 收盘价、股本数量、市值三类输入；
- 价格基准、股本范围、币种；
- 观察时点与公司行动口径；
- verified/unverified/unknown 证据保留；
- 日频 PIT 估值准入规则；
- 确定性目录、内容指纹、构造器不变量和纯合成测试。

## 不包含

公式绑定改造、真实数值、供应商调用、Canonical 写入、市值或因子计算、排序、回测、绩效、组合、风控变更、晋级、账户或订单。

## 验收

只有证据已核验、交易所收盘时点、按交易日当时状态、原始未复权价格基准及明确股本范围的定义可准入；累计调整价、盘中、回填重述和 unknown 均失败关闭；目录顺序和证据计数确定；完整 CI 通过。
