# S6 公式 PIT 就绪总门

- GitHub Issue：#184
- 父任务：#132（归属 #127）
- 起始 master：`f438204c0d044d66c4ed97c5d42d057afb797fb0`
- 分支：`chatgpt/s6-formula-readiness-preflight`

## 目标

将直接财务输入门与直接市场输入门合成同一历史决策时点的公式物化前置审计。

## 包含

- 三层精确指纹：公式绑定、财务子审计、市场子审计；
- 股票和 `as_of` 一致性；
- 财务、市场、派生输入显式计数；
- 子审计行与公式声明逐项覆盖核对；
- 空输入、部分覆盖、失败子门和未展开派生指标失败关闭；
- 无数值、无权限的确定性汇总指纹与合成测试。

## 验收

只有公式绑定准入、至少一个直接输入、所有直接输入完整覆盖并就绪且没有派生输入时，元数据总门才通过；完整 CI 通过。
