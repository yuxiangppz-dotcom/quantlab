# S6-A v6 市场输入公式绑定审计

- GitHub Issue：#169
- 父任务：#132（归属 #127）
- 前置：#165/#166、#167/#168
- 起始 master：`cc751339f1f28397c36551e015e72555a81cd643`
- 分支：`chatgpt/s6-market-input-binding-v1`

## 目标

把已冻结的日频 PIT 市场输入目录接入 S6 公式输入审计，让市场字段与财务字段一样完成 provider/source/semantic ID 精确绑定。

## 包含

- 可选市场目录参数和目录指纹；
- 缺少目录、字段缺失、字段未准入、字段歧义、唯一准入五种结果；
- 派生指标递归继承同一市场目录；
- 旧调用方未传目录时继续显式失败关闭；
- 纯合成绑定测试和中文契约更新。

## 不包含

真实数值、供应商调用、Canonical 写入、公式执行、排序、回测、绩效、组合、风控变更、晋级、账户或订单。

## 验收

市场字段只有在指定 provider/source 下恰好存在一个已准入语义定义时绑定成功；空目录与未传目录保持不同 verdict；歧义不自动择一；派生依赖不能绕过市场阻断；完整 CI 通过。
