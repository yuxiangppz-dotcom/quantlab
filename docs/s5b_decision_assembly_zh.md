# S5-B 决策装配说明

S5-B v1.2 把筑底状态转换成研究用目标组合，但不会直接产生订单。

行业和个股都必须处于 `base_ready` 或 `breakout_confirmed`。历史行业归属必须由
#137 的 PIT 审计确认，研究资格也必须明确为真。归属缺失、未经验证或互相冲突时
保持 `unknown`；归属与候选行业不一致时明确排除，不会使用当前行业分类回填历史。

排序规则在查看收益前固定：突破确认优先于准备完成，然后依次比较低点修复幅度、
20 日区间位置、成交量确认强度，最后用证券代码稳定打破并列。入选数量可以为零，
未使用的权重全部保留为现金。

输出仅表示可复核的研究意图，不证明“主力”身份或未来上涨，也不具备券商下单权限。
