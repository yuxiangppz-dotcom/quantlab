# S6 公式财务输入 PIT 就绪审计

状态：直接财务输入的无数值整合门

## 作用

S6 的公式字段绑定只能证明字段语义已经核验；财务版本库存只能证明某份报表在某个来源时间可见。本审计把两条证据链合并到一个供应商/来源、股票、报告期和决策时点，阻止未来公告、未经核验的最新值或其他来源的数据替代历史可见版本。

## 每个直接财务输入的检查

审计只遍历公式直接声明的 `financial_field`：

1. 公式输入绑定必须准入；
2. 绑定审计必须来自传入字段目录的精确指纹；
3. 绑定的字段定义指纹必须仍在目录内；
4. 版本选择严格限定为绑定的 `provider_id/source_id`、股票、显式报告期和字段所属报表；
5. 只选择 `available_at <= as_of` 的最新已核验原始版或修订版；
6. 所选报表版本必须实际包含绑定的原始字段，且该字段的语义准入证据必须与绑定指纹一致。

成功行固定保存字段定义、所选财务版本和字段准入审计三个指纹。失败会区分绑定阻塞、定义指纹丢失、版本尚不可见、版本未核验、版本缺失、原始字段缺失和字段准入失败。

修订版不会回填到其发布之前：同一库存用更早 `as_of` 审计时仍选择原始版，只有到修订版自己的 `available_at` 后才会替代。

## 就绪结论

- `all_direct_financial_inputs_ready`：至少有一个直接财务输入，且全部通过；
- `financial_gate_ready`：上述条件成立，并且整份公式绑定整体准入。

没有直接财务输入时不会利用空集合声称通过。

## 明确边界

这个门不含财务数值，不执行公式，不解析 `latest_pit_compatible` 的跨期选择，不整合市场输入或派生指标，也不排序、不回测。即使 `financial_gate_ready=True`，`formula_computation_ready` 仍固定为 false，且不产生绩效、组合、风控、账户或订单权限。

下一步是把财务门和已完成的市场门合并为完整的公式物化前置审计；在供应商真实字段、历史版本与本地 Canonical 数据得到核验前，仍不得计算或回测 S6。
