# S6 原始财务字段语义准入契约

状态：provider-neutral、无数值的冻结边界（v1）

## 为什么先做字段准入

同名财务字段可能来自母公司口径或合并口径，可能是期末存量、年初至今累计流量或单季流量，也可能使用不同单位、币种和符号约定。若这些语义尚未核验，直接计算 EP、ROE、现金流质量等指标会制造不可审计的结果。

本契约不定义任何因子公式，只回答一条原始字段是否具备进入后续公式层的资格。

## 字段定义

每条定义由 `provider_id + source_id + raw_field_id` 唯一识别，并明确：

- 稳定的语义字段 ID 与所属报表；
- 时点存量或期间流量；
- 期末时点、年初至今累计或单独期间口径；
- 合并、母公司或 unknown 范围；
- 货币、股数、比率或计数单位；货币字段必须给出三位大写币种；
- 已记录的原始符号约定；
- 证据状态与文档内容指纹。

内部一致性强制要求：时点存量只能使用 `instant`，期间流量不能使用 `instant`；非货币字段不能携带币种。

## 证据状态与准入

只有同时满足以下条件的字段定义才可准入：

1. 证据状态为 `verified`；
2. 有文档内容指纹；
3. 合并范围不是 `unknown`；
4. 符号约定不是 `unknown`；
5. provider、source、raw field 和报表种类与财务版本记录精确匹配。

`provider_documented_unverified` 与 `unknown` 均保留在目录和计数中，但不会获得准入资格。目录缺失、只在另一 provider/source 存在、报表错配也分别形成显式审计行，不能静默忽略。

## 与财务版本契约的组合

字段全部合格仍不代表整份报表可用。最终 `overall_admissible` 同时要求：

- 财务版本为 `original_vintage_verified` 或 `revision_chain_verified`；
- 版本声明的每个原始字段都有完整、核验过且身份匹配的定义。

因此，“字段语义正确”不能挽救“只能看到最新值”的历史版本，反之亦然。

## 明确不授权

目录和审计固定标记不包含数值、不包含因子公式、无绩效结论、无交易权限。它们不接供应商、不读写 Canonical，不进行 TTM/币种换算，也不决定估值或质量因子的分子、分母、方向、阈值和权重。
