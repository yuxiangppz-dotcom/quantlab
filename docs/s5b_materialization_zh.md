# S5-B PIT 特征物化说明

S5-B v1.1 把调用方提供的收盘价、成交量和交易日序列转换为已冻结的筑底状态
字段。模块不连接数据供应商，也不读取决策日之后的数据。

创新低采用严格定义：某日收盘价必须低于该日之前、且不包含当日的 60 个交易日
最低收盘价。仅仅等于前低不会被重复计作创新低。突破也使用不包含当日的前 20 日
最高价，避免用当前价格同时定义门槛和突破结果。

物化结果保留字段级问题与来源指纹。缺交易日、重复日期、非法价格、零成交量分母、
不足 120 日历史或无法定义的波动率都会保持未知，不会填成零。决策日之后的数据既不
改变特征，也不改变问题列表和指纹。

该模块只产生研究观察，不代表策略收益，不修改 Canonical 数据，也没有账户或下单权限。
