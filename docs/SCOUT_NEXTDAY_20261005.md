# Scout 次日研究升级：实现与验收

## 目标与结论口径

本版以目标交易日 D1 的研究机会为主，H3/H5 为辅助。主标签为 D1 收盘价除以供应商 D1 官方参考前收减一，达到 5% 为 strong_close；5% 是预先定义的产品参数，尚未证明最优。除权日不直接用昨天未复权收盘作分母。行业比较使用冻结合格行业成员，而非事后选同行。

D1 复权开盘到 D2 复权收盘只作跨交易日价格代理。它没有排队、成交、费用、滑点或真实卖出，不能称为净收益。预测完成、校验通过和选股有效是三个不同验收项。

普通 A 股日内新买入的回转约束按交易所现行规则核实；本工具不下单。规则依据：[上交所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。指标定义参考：[Tushare 每日指标](https://tushare.pro/document/2?doc_id=32)、[Fidelity MACD](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/macd)。这些定义不证明次日预测有效。

## 实际链路

固定日常配置 `config/scout_daily.fixed.json` 启用 next_session_selection，默认 fused。合格池继续用已有21日完整行情、主板、非ST及成交额门槛；不要求中证800。计算窗口变为120个已完成交易日，逐股缺数、停牌及上市时间不足均保留状态，不填零、不伪造连续行情。

来源窗口从 D0 15:00 到实际输入截点，包含长假。新闻有界分片、历史分片缓存；CNINFO 市场公告及目标股补分页有调用和页数上限。合同/重组等 PDF 用多页机器抽取，保留反证、页段定位与截断，不等同人工核实。正式公布时间、采集时间、首次见到时间分开；没有正式时间不倒填。热榜是注意力来源，评论仍以实际已接入能力显示，不能声称拥有全量同花顺评论。权限或接口失败保留缺口。

160 初筛、24 深查的上限不变。新预算按直接官方正文事件、市场异常、实际更新和重复暴露动态分配；探索最多四分之一，不强制填满。公司直接事件可绕过动量分数门槛。所有来源路径、漏斗、预算排除和探索记录保留，未深查不等于看空。

三个实际阶段使用 `[SCOUT_NEXT_SESSION_V1]`：发现机会→逐股调查→完整比较。只研究已经提供的信息，DeepSeek 不具备额外网页搜索能力。正常三请求、最多四请求、一次定向纠错；32768输出、180000输入字符、300000输入字节、1200000总token、180秒单请求、1800秒流程预算保持。schema、system文本也进入预算检查；调查前预留最终新增内容。没有无限历史回复或临时增额。

模型给研究排序、D1条件、比较差异和反证。程序计算数值、主体、期间、单位、校验与展示。peer 来自冻结行业/题材/机会关联，可同样入选；独特直接事件可以没有同行，但须显示不可比。证据不足对象不可排序或入选。focus 需要可观察条件、有效研究规则、可核查差异及可用技术事实；官方事件条件绑定同一实际官方正文事件。仍允许不选。

## 技术与事实表

`technical.py` 的版本固定为 technical_d0_v1_120_sma_seed_wilder14_macd2：

- MA5/10/20/60、五日均线斜率、MA20偏离、20/60日高低区间、排除D0的20日突破、近20日回撤。
- 实体/影线/收盘位置/缺口；成交额、成交量的五日放大分开；换手及流通市值口径独立。
- Wilder ATR14/RSI14；MACD12/26/9采用SMA种子、EMA系数2/(n+1)，柱值2×(DIF−DEA)，连续78日暖机。保存原值及对价格标准化值。
- 20日样本波动率不年化；近10日方向、涨跌日数与短序列只是相关价格家族，不能充当多条独立催化。

价格统一以D0因子锚定的复权研究价计算，成交约束保留原价。缺少/无效/无交易活动会中断暖机。指标依赖与120日原序列只保存深查池审计；模型收到技术状态、必要缺口和事实。

新版 typed_dictionary_v1 在事实表内用字典编码主体/指标/期间/单位，保留原始 value；程序 `unpack_facts` 无损还原。技术身份以事实行索引标识，公告日以稀疏元数据保存。字典索引不是数值；Prompt明确说明。单位未核实的财务数字从可引用数值表移除并按主体记录遗漏数，原值仍在原始审计。不会把未知单位提升为人民币或比率。压缩不修改原输入。

结构化研究撤销与参与取消分开。MA20、相对强势规则参数由程序固定；截点已失效不支持重点。D1收盘自动观察价格规则；事件取消缺正式后续状态则待人工核查，保持未知。开盘限制取消只取消未参与计划，不推断开盘成交或持仓止损。

## 输出、冻结和观察

HTML、Markdown、微信共用六项卡：类型/状态、关注理由、同类差异、技术位置、最强反证与程序风险、确认与取消。详细来源/漏斗不占日常主体。已知停牌仍可研究，但参与状态独立保留限制。

新报告保存原始回复、三个请求的实际文本SHA/schemaSHA、固定配置、实际引擎/应用身份、D1目标和发布时间上限。原报告不重写。云端实际发布回执绑定原报告哈希；云端本地保存不能冒充公网已经发布，9:00后发布不进入正式盘前主样本。

次日协议冻结完整深查池、排名、弃选、原score同k基线、全池基线、行业成员、来源缺口、条件与规则。按版本隔离，报告/个股/日期分母、未知、缺失正式日期、推荐覆盖均保留；重复正式日期为协议错误。错误归因为未召回、预算排除、排序/分级、扩张、参与限制等，不能事后换名单。

私有云工作流保留北京时间08:03/08:23/08:43；新增18:10/20:10零模型观察。晨间也做有界补查。观察领取和预测日领取独立，写归档互斥。65分钟工作流硬超时之后，70分钟无checkpoint可隔离旧写入者，但永不释放原付费日领取再预测。模型送达未知不补发。免费调度延迟或缺数据仍保存失败/未知。

120日历史必须先在Scout隔离卷准备好，日常盘前只做增量；prepare每批最多40分区、8个批号，总供应商请求与时间仍有界。不改原canonical；不删除缓存、旧报告、失败或通知意图。
