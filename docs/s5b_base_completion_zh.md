# S5-B 筑底完成状态说明

S5-B 不尝试识别不可观测的“主力”，只判断价格和成交量呈现出的筑底结构。
它与现有 S5-A 完全分开，不覆盖已经冻结的 S5-A 规则。

## 为什么创新低不直接判失败

10～20 个交易日的底部震荡中，出现一次浅度新低并不罕见。若跌破幅度小、
波动没有扩张，并且三日内收回前低，这种情况仍可进入 `base_ready`。只有跌破
过深、近期跌速或回撤过大、波动扩张等结构性恶化才进入 `failed`。

新低次数较多但跌幅仍受控时，状态是 `base_building`，含义是“仍在筑底”，
而不是直接否定。这样保留了你的核心判断：新低是否危险，要看深度、速度、
波动和修复，而不是只看有没有新低。

## 状态含义

- `unknown`：必要的历史或字段缺失，拒绝猜测；
- `base_building`：尚未恶化，但修复和结构条件未全部完成；
- `base_ready`：底部结构成立，尚未获得完整突破确认；
- `breakout_confirmed`：价格突破且成交量同步确认；
- `failed`：出现明确的结构性失效。

状态结果固定标记为研究用途，不代表收益结论，也不具备交易权限。下一步需要
单独开发 PIT 特征物化层，之后才能对冻结规则做一次受约束的历史诊断。
