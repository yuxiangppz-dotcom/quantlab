# 二十条公司行为的原始公告与分配对象核对

本批发现一个会导致未来股数回放高估的具体陷阱：公司新增股本不一定分给
原股东。002217 的2024年重整公告虽然写每10股转增14股，但第3、8页明确
将新增股份分配给重整投资人和债权人，原股东不能按1.4比例获得新股。
新增研究校验把“比例和日期齐全”与“原股东有按比例分配的证据”分开。
此前最小字段适配器没有实际记账，本次不是修正已经测出的收益。

固定范围为上一批20条税前现金未知的实施记录，不扩股票、不读取绩效。
20次查询额度全部使用，部分精确日期查询没有找到有效原件；共打开9个不同
公开地址，下载4份此前成功读取的原始PDF，共1,397,723字节，零重试。
没有调用Tushare。全部搜索及失败记录、原始字节和逐条注释保存在
`data/products/research_program/launch_20260912/corporate_20_primary_review/`。
