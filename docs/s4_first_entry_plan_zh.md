# S4第一笔研究建仓的具体输入

把已保存的反转信号连接到明确的首次建仓提案：2021年12月31日形成信号，
计划2022年1月4日尝试执行。原256只研究股票全部保留；至少30个有效信号时，
按分数从高到低选20个原始提案，同分按证券代码排序。这一步还没有证明它们
满足历史ST、生命周期及交易条件，不能作为推荐清单或已成交股票。

资金按20万元、80%名义股票目标、20个等额位置，每个位置8000元。股数只按
信号日的未复权收盘价和已审阅的收盘限价基本数量规则向下计算；交易日价格、
成交量或事后状态都不能改变入选名单，买不起、未知或不能成交也不拿第21名
补齐。这里的名义股数没有冒充费用已经预留的可执行委托。

新对象显式接入之前保存的20日成交额保守下界；原始数据和169只严格整数分
口径保持不变。基准和压力费用上下文事前固定为5bp、15bp不利滑点假设，均用
1%容量假设；它们不是实际点差，后续5%容量敏感性要另计路径。沿用用户申报
佣金和当期卖方印花税，未核实的附加费用仍为空，因此不会输出完整交易费用。

报告只列所选、需要正股数建仓的证券缺哪些必要事实，避免被未持有股票的
公司事件拖入无限审计。市场状态、公司行为、历史身份/资格和未核实费用仍
分别保留未知；不运行真实输入调度器，没有净值、收益、回撤或经济路径。
纯合成测试不证明历史表现。下一步应按固定提案核实最小必要事实，而不能
重复生成同一提案，也不能把未运行当作零收益。
