# 金额精度问题：增加保守的流动性下界，原数据不改

原首日回放输入要求成交额能精确转换为整数分，因此仅 169/256 只股票具有完整
20 日平均成交额。142 个未知股日中，56 个确实缺行，另 86 个是有限但带不足一分
尾数的数值。部分尾数与浮点单位转换的误差形式一致；本次没有把这一推断当作
原始交易所成交额已被还原的证据。

新增一个独立的流动性金额下界：把保存的元数值按十进制精确乘 100，再向下取整
到分；连续 20 个交易日均有有效观察时，对每天的下界求和并向下计算平均值。
这个数不会高于相应已保存数值，可用于后续保守的成交容量估算。它不用于股票
价格、费用、账户现金或分红，不会将未知金额补成零，也没有自动接入历史控制器。

同一固定窗口（2021-12-06 至 2021-12-31）和同一 256 只样本的一次计算结果：

| 口径 | 结果 |
| --- | --- |
| 原精确到分的完整平均额 | 169 只，全部保持原值 |
| 新完整保守平均额下界 | 247 只 |
| 向下处理的不足一分观察 | 86 个股日 |
| 仍未知并保留的观察 | 56 个股日，9 只股票尚无完整平均额 |

额外 78 只有了可核对的保守平均额下界，并不等于股票已可成交。原始分区、旧
observations/report/proof 和旧的 169 只结论均未改写；新结果是另一种明确命名的
计算口径。参与率上限、逐股状态、收盘情景和公司行为等仍须各自通过检查。
新投影目前仅处理此前 20 日平均额，没有改动执行日价格或成交额字段。
