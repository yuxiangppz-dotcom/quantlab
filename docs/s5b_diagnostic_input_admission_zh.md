# S5-B 冻结诊断 outcome 输入验入

该模块位于 outcome-free readiness 与统计计算之间。它不会访问本地 Canonical，
也不会计算收益好坏；它只接受调用方已经物化的标签，并验证输入包没有漏样本、
换样本或缩短观察窗口。

## 必须完整一致的网格

- 信号人口必须与 readiness 所绑定的 eligibility evidence 完全一致；
- 每个股票/信号日必须恰好有 1、5、10、20 日 close-to-close 标签；
- 每个信号日/窗口必须有中证全指标签；
- 协议中的五个 comparison id 必须在每个信号日/窗口都有一行；
- 同一信号日/窗口的股票、基准和对照必须指向同一个 label end date；
- `broad_market_control` 必须与中证全指基准值完全相同。

任何缺失、额外或重复行都直接失败，不能先删除不完整样本再计算。

## 目标一致性

被选中的股票必须来自 `eligible` 且处于 `base_ready` 或
`breakout_confirmed`，使用冻结的单股 4% 研究目标；未选中股票权重为零。
每个信号日所有股票权重与现金之和必须为 1，最多选择 20 只。

这里的权重只是信号日研究目标。outcome 是信号日收盘到未来收盘的标签，不是可执行
持仓收益、成交结果或账户 PnL。输入包始终标记为历史已观察、诊断用途、无绩效声明
和无下单权限。
