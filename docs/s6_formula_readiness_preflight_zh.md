# S6 公式 PIT 就绪总门

状态：财务门与市场门的无数值汇总审计

## 作用

财务输入和市场输入分别通过，并不自动证明它们属于同一次历史决策。本总门要求两份子审计绑定同一份公式输入审计、同一股票和同一 `as_of`，再核对公式声明的每一个直接输入是否被对应子审计完整覆盖。

总门保存公式绑定、财务子审计和市场子审计的精确指纹，并记录显式报告期与市场交易日。不同报告期和交易日可以共存，但决策可见时间必须完全一致。

## 通过条件

只有同时满足以下条件，`metadata_preflight_ready` 才为 true：

1. 公式绑定整体准入；
2. 财务和市场子审计绑定同一公式绑定指纹；
3. 两个子审计的股票与 `as_of` 一致；
4. 子审计行与公式声明的直接财务/市场输入逐项一致；
5. 至少存在一个直接输入，且所有直接输入就绪；
6. 没有尚未展开的派生指标输入。

空公式、部分覆盖、失败的任一子门或残留派生输入都不会通过。

## 边界

这里的“就绪”仅指元数据证据链完整，不代表已经拥有数值。总门不读取供应商或 Canonical，不执行公式，不做单位换算、TTM、排序、选股或回测；`formula_computation_ready` 固定为 false，也不授予绩效、组合、风控、账户或订单权限。

真实数据缺失时，S6 的安全公共基础设施到这里已经闭环。后续必须先核验真实供应商字段定义、历史版本和本地数据，再冻结候选公式及其会计口径。
