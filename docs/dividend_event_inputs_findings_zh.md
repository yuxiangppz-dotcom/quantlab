# 分红事件与固定策略窗口：结果与使用方式

本轮将4,516只股票的217,007条原始观察全部保留，并关联到已有的107,400个研究窗口。
其中3,312个窗口包含分红候选，共3,495次关联，涉及913条不同原始观察。模型和期限之间
的窗口可能重叠，不能把关联次数累加成独立分红次数，更不能直接算成现金收益。

在 QuantLab 的“回测与基准”页面查看“分红事件与策略持有窗口”。可下载关联报告、
模型与期限汇总、版本待核对清单、独立复核和本中文解读。原始补数结果仍在下方。

## 为什么不能把这些记录当作当年的信号

原始响应的本地观察时间为2026-09-11 UTC，即北京时间2026-09-12；所有被关联窗口的
信号截止不晚于2026-09-10。因此“在当时信号收盘前本地已观察”的候选为0。公告日期
可以描述事件公开日期，却不能倒填本系统实际取得数据的时间。

这是用于事后核对的历史资料。未找到候选不能证明没有公司行为；170,028条没有有效权益
日期的原始观察仍在未解决池中。300条现金为正、发放日未知的实施记录没有已知权益日期
落在固定研究范围内，其未知日期相关性依然没有被排除。

## 验证与边界

独立程序直接解码全部原始响应，核对每一条观察的原始字段、日期、数值、单位、身份和
UTC时间，再从原始107,400个窗口独立计算全部3,495次关联，没有调用适配器的映射或
关联函数。边界样例覆盖登记日恰好等于起点或退出、退出后现金/股份日期、状态尾空格、
无日期和未知起止。全部数量与封存报告一致。

实际适配约13.49秒，峰值内存约351.73 MiB，结束时暂存约37.74 MiB；独立复核约13.55秒，
峰值约1.43 GiB。计算和Arrow线程均限制为2。本轮没有请求数据源、真实模型拟合、修改
正式数据、生成账户权益/税额/成交/收益、前瞻登记或策略晋级。

## 下一步回到策略能力

已有窗口并未碰到那7组版本冲突，下一步优先研究固定策略的预测稳定性、成本影响与
每周候选训练方案，避免无限追查与这些窗口无关的久远历史。先固定比较对象、标签成熟
要求、数据截止、训练频率和评价标准，再做实验。2026年数据已经被观察，后续只能称为
回顾性诊断，不能重新包装成未见样本或前瞻证据。

Alpha101和Alpha191逐项核对公式与依赖后再与Alpha158比较。每周重训不等于每周调参或
自动换策略。“大涨后急跌使2026年变弱”仍是待检验假设。复杂风险层在策略能力获得
证据支持后展开，保留基本仓位边界与空仓能力；收益和最大回撤20%的目标仍未验证。
